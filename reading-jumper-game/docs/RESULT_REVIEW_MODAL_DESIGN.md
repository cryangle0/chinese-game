# 答题回顾完整内容弹框设计

## 范围

- 阅读、写作两个游戏的结算页。
- 每一道答题回顾条目均可点击。
- 同步修复阅读游戏反馈期间分数抢视觉、下一题小鹿未复位。

## 交互

点击某一道回顾后，显示游戏化遮罩弹框。弹框包含题号、完整题干、我的答案、正确答案和对错状态。点击关闭按钮、遮罩空白处或按 Escape 关闭。

结算页原有条目保留摘要展示，不再要求用户横向拖动才能查看完整内容。弹框正文允许纵向滚动，以适应长题干和小屏设备。

## 实现

- 在两个项目的 `DomResultReview` 中复用同一套 DOM 弹框结构和生命周期管理。
- 回顾数据补充题号、题干、用户答案、正确答案与结果状态，不从摘要文本反向解析。
- 弹框颜色、圆角、描边和按钮采用现有橙金色结算风格，不引入新素材。
- 结算节点销毁时移除所有 DOM 元素和事件监听，避免跨场景残留。
- 阅读游戏在反馈结束、展示下一题前将小鹿复位到中间列；分数 HUD 延迟到反馈结束后更新。

## 验收

- 点击任意回顾条目只显示对应题目完整信息。
- 长题干在弹框内完整可读，可纵向滚动。
- 遮罩、关闭按钮和 Escape 均可关闭弹框。
- 阅读下一题开始时小鹿位于中间列，反馈播放期间分数不提前变化。
- 按用户要求，本轮由用户自行进行运行验收。

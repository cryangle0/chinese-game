# 跳跳乐测试与验收

## 自动门禁

- TypeScript strict、单文件不超过 180 行、`games/` 目录只含阅读实现。
- 题库、抽题、计分、计时、状态机和生命周期单元测试及覆盖率阈值。
- 源资源不超过 10MB、单资源不超过 2MB、Web 构建产物不超过 17MB。
- Creator 3.8.8 生产构建、桌面 1440×810 与移动 844×390 E2E。
- 五个正式切图主题分别直达启动，校验独立资源路径、画布非空和运行时异常。
- `npm run check:visual` 比较桌面 7 个、移动 7 个固定视觉基线与 E2E 截图的静态区域，输出 MAE、RMSE、
  最大通道差异和差分热图，并在超阈值时返回非零。
- `npm run check:visual:self-test` 会篡改单个未遮罩像素，验证门禁确实会失败。
- `npm run check:design-visual` 对原始示意图的静态区域执行带阈值差分。
- 正式题库门禁拒绝未审批、内容重复率过高和缺少分年级内容的数据。
- 首屏不超过 7 秒，30 帧采样不超过 1.5 秒，画布像素非空。

像素门禁不是整张设计稿的零差异比较：计时、题目文本、角色动画、答题结果和摄像头
等动态区域按场景遮罩，背景、切图和静态几何仍会被严格比较。它不能证明相对原始
设计稿已经逐像素一致，原始设计稿审计和残余差异仍见 `docs/PIXEL_ALIGNMENT_AUDIT.md`。

## 功能场景

1. 开场按钮连续点击只启动一次。
2. 三个选项触控区域清晰，反馈期间重复点击无效。
3. 每个场景连续完成五题，前四题不切场景，第五题后显示该场景结算。
4. 进入下一场景时积分、场内答题记录和连击清零，生命保留，倒计时重新开始。
5. 前四场使用“进入下一场景”中间结算，第五场进入最终结算；生命耗尽、超时、空题库和运行错误仍直接终局。
6. 场景顺序来自主题配置，当前为马里奥、深海、星际、美食、诗词，后续可按客户确认结果调整。
7. 正负反馈、积分变化、重玩、返回宿主和错题回顾正常。
8. 远程题库失败时使用缓存或内置题。
9. 页面隐藏时计时和音频暂停，恢复后继续。
10. 允许摄像头后，右上角预览进入“体感已连接”，身体左右移动选择三列，跳起提交答案。
11. 摄像头拒权、模型加载失败或连续推理异常时自动切换触屏，不阻塞题目和倒计时，并允许重试。

## 真机

上线前仍需覆盖 iPhone 12+ 与主流华为/小米/OPPO/vivo 近三年机型，记录 FPS、峰值内存、DrawCall、弱网表现和连续运行 30 分钟后的内存变化。桌面模拟不能替代真机报告。

## 运行时性能门禁

`npm run benchmark:runtime` 执行三个完整场景周期；一个周期包含同一场景的五道题和一次结算，前四场继续到下一场，第五场结算后重开整轮。它记录启动、初始/累计传输、交互帧 p50/p95/p99、Long Task、DrawCall、三角形与强制 GC 后堆增长。门禁为：启动不超过 1,500 ms、初始传输不超过 2.5 MB、p95 不超过 25 ms、p99 不超过 50 ms、最长任务不超过 250 ms、DrawCall P95/峰值不超过 35/40、三角形 P95/峰值不超过 450/500、三轮堆增长不超过 2 MB。该命令已进入 `check:release`，应单独串行运行，避免其他 Chrome/Cocos 任务争用机器造成噪声。

`npm run benchmark:runtime:long` 执行 10 个完整场景周期，即两轮五场景活动，并额外要求后半程堆增长和任一单轮堆增长均不超过 1 MB。它用于提前发现切场景和重开路径的增长趋势，但不能替代真机连续 30 分钟报告。

`npm run benchmark:runtime:soak` 按实际墙钟运行 30 分钟，持续记录帧时间、Long Task、
DrawCall、三角形、运行时异常和逐周期强制 GC 后堆趋势，并每 10 个周期冻结/恢复页面，
恢复超过 3 秒或出现运行时错误会失败。报告独立写入
`test-results/performance/runtime-soak.json`。该工具能发现浏览器长时回归，但仍不能采集
微信真机发热、耗电和原生峰值内存。

`npm run benchmark:pose` 使用发布包内真实 TF.js 与 MoveNet Lightning 模型做首次和热推理测试。2026-07-15 本机无头软件 WebGL 结果为首次就绪约 12.08 秒、热推理 p95 约 48 ms、传输约 4.91 MB。该数据证明模型可运行，但软件 WebGL 不代表手机 GPU；正式验收仍需 iOS/Android 微信真机记录首次授权、首次就绪、热推理延迟、温升和耗电。

## 2026-07-16 最终自动化结果

- `npm run check`：架构、项目同步、小程序壳、250 题、6 个服务端测试和
  19 suites/56 个 Jest 测试全部通过。
- 覆盖率：语句 84.21%、分支 73.86%、函数 91.05%、行 89.03%。
- Web 构建：249 个文件、16.29 MB；初始资源 3.56 MB，体感延迟资源 6.48 MB。
- `npm run test:e2e`：桌面与横屏移动端完整 25 题、逐场结算、最终结算和重玩通过。
- 冻结视觉基线 14/14、门禁单像素自检、原设计静态区域 10/10 全部通过。
- 10 周期门禁：ready 958.7 ms、p95 17 ms、p99 22.7 ms、最长任务 81 ms，
  DrawCall P95/峰值 17/29、三角形 P95/峰值 67/266、堆总增长 1,135,488 bytes，
  后半程增长 223,384 bytes。
- 5 分钟桌面 soak：34 周期、3 次前后台恢复、运行时错误 0、p95 17.4 ms、
  p99 24.5 ms、堆总增长 2,081,784 bytes、后半程增长 305,540 bytes。总增长距离
  2 MB 门槛只余 15,368 bytes，虽然后半程趋稳，仍需 30 分钟真机继续验证。
- WASM 回退实测可用：首次就绪 166 ms、热推理 p95 31 ms；已删除未使用的多线程
  WASM 变体，仍保留 SIMD 与普通 WASM 两套兼容文件。

这些结果不替代真机 30 分钟稳定性、发热、耗电、峰值原生内存和弱网验收。

# 阅读跳跳乐像素对齐审计

审计日期：2026-07-16

## 当前结论

五主题答题页、五主题结算页和正式开场页的主要静态切图、背景取景及组件几何已接入，
并建立了会返回非零退出码的像素差分门禁。当前可以确认“相对冻结基线无静态视觉回归”
以及“原稿静态区域在设定容差内”，不能称为整屏零像素差异。

原包没有授权字体文件，也没有深海、星际、美食、诗词角色的逐帧动画。摄像头实时画面、
题目、分数、排名和角色动画属于动态区域，必须用遮罩或几何断言验收。

基准为原包 `2560x1440` 示意图 Lanczos 缩放后的 `1440x810` 图片。下表为
`npm run check:design-visual` 最新结果，已遮罩动态文本、动画角色和动态结果区域：

| 页面 | MAE | RMSE | 通道差异大于 16 的像素 |
|---|---:|---:|---:|
| 正式开场 | 6.00 | 21.08 | 10.94% |
| 基础版答题 | 2.99 | 13.43 | 4.37% |
| 深海龙宫答题 | 2.70 | 9.36 | 3.62% |
| 星际穿越答题 | 2.04 | 6.34 | 2.55% |
| 诗词山水答题 | 2.35 | 7.91 | 4.19% |
| 基础版结算 | 8.27 | 27.61 | 11.59% |
| 深海龙宫结算 | 5.46 | 19.44 | 8.29% |
| 星际穿越结算 | 4.29 | 18.76 | 5.83% |

美食大冒险没有答题页示意图，不能给出该页相对原稿的量化结论。结算页差异仍明显高于
答题页，主要来自动态组件、产品新增操作按钮、字体和原稿静态文字之间的差异。

## 已完成校准

1. 16:9 桌面背景按设计视野显示，超宽移动端使用响应式背景宽度。
2. 五主题分别配置题板、选项、角色、计时和积分 HUD 的位置及尺寸。
3. 正式题板加载后不再叠加 fallback Graphics；五主题文字使用独立描边色。
4. 五主题结算页已按原切图区域重建分数、星级、排行榜和答题回顾。
5. 开场已接入正式“阅读跳跳乐”标题、引导词、金币桶、开始按钮、角色及管道前后层。
6. 摄像头空框在开场预展示，点击开始后才请求权限；桌面框约 `328x188`，
   横屏移动端约 `190x110`，ready 状态隐藏标题栏和人体虚线。
7. 马里奥使用 6 帧待机和 22 帧跳跃图集；其他主题的视觉节点与移动根节点分离，
   并提供程序化呼吸、升降及跳跃反馈。

## 自动门禁

- `npm run check:visual`：14 个冻结基线场景通过，覆盖桌面和 844×390 横屏移动端的
  开场、五主题答题与最终结算；未遮罩静态区域最大差异为 1。
- `npm run check:visual:self-test`：篡改单个未遮罩像素后可检测并判失败。
- `npm run check:design-visual`：10 个原设计静态区域场景通过。
- E2E 另行断言桌面/移动摄像头几何、ready 状态、角色连续像素变化和 25 题流程。

动态题干和选项遮罩按实际 Label 边界设置，题板边框、铆钉、砖块边缘和背景仍参与
严格比较。开场只遮罩呼吸角色，标题、金币桶、按钮、管道和摄像头空框均参与比较。

## 尚未完成

- 非马里奥主题没有原始逐帧动画；程序化呼吸不是原画连续动画的等价替代。
- 当前使用 `Microsoft YaHei` 系统字体；素材包没有授权字体，跨真机无法逐像素一致。
- 摄像头实时内容天然动态，自动化只能固定空框/模拟流并校验几何和状态。
- 结算操作按钮是产品新增交互，原示意图没有对应基准。
- 原设计差分仍有 2.55%-11.67% 的大于 16 通道差异，不能宣称零差异。
- 尚未建立 iOS/Android 多机型安全区截图和真机字体基线。

完整指标见 `test-results/design-audit/masked-metrics.json`，差分热图位于同目录；
冻结基线指标见 `test-results/pixel-gate/metrics.json`。

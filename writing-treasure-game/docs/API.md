# 服务接口

## `GET /health`

返回服务时间和健康状态。

```json
{"ok":true,"bankVersion":"20260706_v1","time":"2026-07-12T00:00:00.000Z"}
```

## `GET /api/bank`

返回题库版本包。客户端立即使用缓存/内置题，远程成功后原子替换；失败最多重试三次。

```json
{"version":"20260706_v1","generatedAt":"...","questions":[]}
```

## `POST /api/track`

请求体为 `{"events":[]}`，单请求限制 256KB、每批 1 到 50 条，并校验事件结构。
参考服务仅对该接口按客户端地址限流。成功返回 HTTP 202：

```json
{"accepted":20}
```

生产环境应将 JSONL 接入日志采集系统，并配置文件轮转、磁盘告警和脱敏策略。

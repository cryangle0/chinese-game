# chinese-game

作业帮语文互动小游戏（Cocos Creator 3.8.8 + TypeScript）。

## 项目结构

| 目录 | 游戏 |
|------|------|
| `reading-jumper-game/` | 跳跳乐 |
| `writing-treasure-game/` | 挖宝 |

每个子目录均为可独立打开、安装、构建和部署的完整工程，详见各自 `README.md`。

## 快速开始

```powershell
cd reading-jumper-game   # 或 writing-treasure-game
npm ci
npm run check
npm run build:web
npm run serve
```
